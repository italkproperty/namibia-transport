# Vehicle decal — namibiatransport.com

Artwork for printing or cutting onto a vehicle. Give your sign-maker this
folder.

## Files

| File | Use |
|---|---|
| `namibiatransport-com-dark.pdf` | **Vector.** Ink on transparent — for a white or light vehicle. |
| `namibiatransport-com-white.pdf` | **Vector.** White on transparent — for a dark vehicle. |
| `namibiatransport-com-dark-600dpi.png` | Raster, 14175 × 1206 px, transparent. For printed vinyl. |
| `namibiatransport-com-white-600dpi.png` | Same, white. |

## Size

Artwork is **600 × 50.9 mm**, trimmed tight to the letters — there is no
margin, so setting the width to any size scales it exactly. At 600 mm wide the
lowercase letters are about 30 mm tall and the ascenders about 39 mm, which
reads at roughly twelve metres.

Suggested: front doors 500–600 mm · tailgate 400–500 mm · rear window 300–400 mm.

## Colours

- Ink `#11151a` — near-black, the brand's text colour. Not pure black.
- White `#ffffff`

For cut vinyl, the nearest standard film to the ink is a black or very dark
charcoal; matching `#11151a` exactly is not worth paying for.

## For your sign-maker

The typeface is **Archivo, Bold (weight 700)**, with letter-spacing of +0.01 em.
Archivo is free and open-licensed, from Google Fonts:
<https://fonts.google.com/specimen/Archivo>

That matters because of how the PDFs are built. The glyphs are embedded as
vector outlines, so the files are self-contained and nothing will substitute a
different font — but they are embedded as a **Type 3** font, which some
cutting software imports awkwardly. If your software objects, the simplest fix
is to install Archivo, set it to Bold with +0.01 em tracking, type
`namibiatransport.com` in lowercase, and convert to curves. It will match this
artwork exactly, because this artwork is that.

The 600 dpi PNGs are the fallback for large-format digital printing and need no
font at all.

## Why lowercase

A domain in lowercase reads as a web address; in capitals it reads as a brand
name and people are slower to recognise it as somewhere to go. The brand
wordmark itself is uppercase — that is the logo. This is the address.
